# 0.51.0-rc1：在渲染线程省略视野外的刚体

目标是初代 Switch 实际战斗稳定 60 FPS。本版真机重战斗 44.37 ms/帧，游戏线程 43.48 ms/帧；对照版 0.43.0 为 50.53 / 49.68 ms。

候选包保留 256 KiB 及 0.50 的 ARM 优化。对原版使用的三种固定功能刚体
格式，先用实际着色矩阵测试当前顶点。一旦没有同一个侧裁剪面能排除所有
顶点，就保留绘制；接触裁剪面的情况也保留。通过时才省去纹理和管线准备、
顶点上传及 Vulkan 绘制。按当前顶点内容判断，不使用上一帧的可见性。游戏
可见性报告、蒙皮、程序顶点着色器和连续辉光走原路径。

**重战斗第 1801–1920 帧，宿主软件 Vulkan，一次回放内交替开关**：

| | 原路径 | 逐顶点侧面测试 |
|---|---:|---:|
| 游戏请求的绘制/帧 | 677.8 | 678.0 |
| 渲染器实际准备的绘制/帧 | 677.8 | 552.8 |
| 渲染线程 CPU（本帧首次 Draw 至进入 Present） | 3.492 ms | 2.732 ms |

59 对相邻帧，测试组每帧省略 125.2 次，CPU 省时 0.760 ms，8 帧分块
重抽样区间 [0.401, 1.173] ms。1681–1800 帧测得 2.491 → 2.318 ms，
区间跨零。以上不包含 Present、GPU 或游戏线程，不是 Switch FPS。
实装候选包在其重战斗最后 120 次呈现中省略 15,707 次绘制。

**将这些绘制对应回游戏线程**：把独立编号随绘制命令送到渲染线程，
逐笔核对 120 帧中的 75,484 个原模型提交、75,346 次绘制。14,606 次
提交的全部绘制都可证明在视野外，其原提交函数在游戏线程上合计
**0.2824 ms/帧**；其余有绘制的提交占 1.2368 ms/帧。没有丢失命令。
这是包含探针的宿主整段计时，尚未证明提前跳过整个提交是安全的；
0.2824 也不是本版在游戏线程省下的时间。

同一候选包的 ARM 游戏对象已离线通过内核、文件、退交/重交内存和回调
寄存器测试，跑完 1920 帧自动演示战斗，并从菜单开新游戏，在第一章
出生点通过两次停步与反向移动测试（第 1537 次场景翻转）。单独的
10 万例齐次三角形裁剪参考测试有 31,669 例被快速判定排除，没有误删
与视野相交的三角形。GPU 采样验证及初版包围盒对照见
[0.50 实验记录](switch-0.50.md)。

NRO 已验证版本与 RomFS；已上传并从 SD 回读核对。不会在 SD 上另建裁剪缓存。SHA-256：

    fb530634a45fd9e50f1bebc3a3b6c02cd833ecb530cc808d719d32dcac5a1c88

另用正式版的剔除判断和候选包的游戏对象跑一次对照：将所有判断为可省略且
到达 Vulkan 绘制点的调用恢复执行，逐笔开启 GPU 查询。115 个观察到的场景帧
共 15,523 次；每一次的裁剪输出、片元着色器调用和通过的样本数都为零。
原版可见性报告照常执行，查询额外开销不用于计时。

候选包游戏对象另跑了完整的无输入回归：最后一次周期记录是场景翻转
9240，随后图像检查确认演示自然返回标题（clip-natural.log）。


真机复测（0.51.0-rc1，相同 1020/307.2 MHz）：开场 120 帧 34.10 ms，
重战斗 120 帧 44.37 ms（旧版 50.53 ms）。新版重战斗游戏线程 43.48 ms，
P95 墙钟 49.41 ms，120 帧全部超出 60 FPS 预算。设备记录位于
build/switch-runtime/device-logs/0.51.0-rc1-attract-20261113-103856。

按栈中是否包含有序渲染列表分组，重战斗 407 个游戏线程样本中，205 个
不在列表内，58 个在列表内但不在共享模型提交函数中，144 个在该函数内。
这 144 个里 65 个处于索引绘制调用（包括捕获与记录），20 个处于材质路径，
20 个处于初始配置，其余 39 个。样本互斥；不能把整个列表成本都算作裁剪收益。
四个主要回调的细分见同目录 render-path.txt。

离线模型提交的前后帧按模型地址及其在帧内出现的次序对齐。上一帧全部在外的
可匹配提交有 14,201 次，本帧 260 次不能再次证明全部在外；单纯复用可见性不安全。
14,606 个全部在外的提交分成 3,560 段，中间没有同帧的其他提交。此处的相邻性
并不表示它们属于同一个可裁剪对象；按回调的真实动态边界另行测量。

将另一轮 1920 帧回放中的每个 Draw 随命令追溯到最外层排序回调，而非按相邻调用推测。
重战斗 120 帧逐笔闭合 55,939 个回调、81,430 次绘制。6,335 个回调的全部绘制均被
侧面裁剪排除，对应 8,893 次绘制；另外 8,243 次被排除的绘制在有其他输出的组中。
全部排除的组在该宿主回放仅占 0.162 / 2.038 ms 每帧的回调 CPU 区间，而且仍需保留其副作用。
因此提前剔除整个回调不是填补真机 27.71 ms 差额的主要手段。耗时包含回调返回前的
线程执行，不等于 Switch 周期；没有在机器上跳过任何回调。实验 group-clip.log。
