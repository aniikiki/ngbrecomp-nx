## 已验证的不等价分支

Xbox 地址 001E0175 的路径经过 AND 0x7fffffff，结果符号位和溢出标志均为零；
001E017F 的 JGE 必须跳过调用。生成代码却读了初始化为零、没有更新的 _flags。
实际 NRO 快速栈路径走到 01E1CD68，调用 0036F440，压入 Xbox 返回地址 001E0188。
[witness.py](witness.py) 分别执行原 XBE 与发布 NRO 的对应代码块，四组输入全部复现。
其他前驱使用 CMP，所以不能把 JGE 一律改为跳转。没有证据表明此路径造成菜单掉帧。

扫描生成的 C 找到 128 个函数、139 个条件码回退读取点，包括条件移动和条件置位。
131 个可从块首线性解码匹配原版助记符，横杠表示此方法未定位。链接了某个段不等于
实际执行它；例如图标逻辑已有 Switch 链接覆盖。该清单是筛查结果，不是缺陷数。
现有条件码合流、函数合并、循环相关测试 158 项通过。[菜单计时对照](../mission-menu-findings.md) 独立于本次静态检查。

## 复查方法

从仓库根目录，将 link.py、spans.py、check.cpp、check.sh 复制到空的临时目录。
容器内把它挂载为 /audit、仓库挂载为 /work 并以 /work 为工作目录。
在原打包环境执行 python3 /audit/link.py（完成临时链接即退出），在 ngb-switch-nxvk:dev
执行 sh /audit/check.sh；检查 issues.tsv 是否为空。宿主机使用含 Capstone 的 Python
运行 inventory.py 临时目录路径；使用含 Unicorn 的 Python 从仓库根目录运行 witness.py。
