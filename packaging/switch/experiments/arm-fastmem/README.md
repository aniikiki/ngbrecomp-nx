Linux/AArch64 experiment only; not compiled into the Switch application. Two virtual mappings reference the same backing RAM. The sparse guest mapping protects unmapped pages. A fault at a registered scalar access site branches back to the ordinary checked implementation. The standalone check exercises mapping, aliasing, protected pages, MMIO fallback and unmap/remap. No libnx exception handler or Switch VM mapping is supplied. Do not use it as a general-purpose replacement for the guest memory helpers.
